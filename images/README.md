# 图片资源目录

请在此目录添加以下图标图片：

## TabBar 图标（建议 81x81 px）
- `tab-home.png` / `tab-home-active.png` - 首页图标
- `tab-order.png` / `tab-order-active.png` - 订单图标  
- `tab-me.png` / `tab-me-active.png` - 我的图标

## 其他图片
- `default-avatar.png` - 默认头像（建议 200x200 px）
- `qr-placeholder.png` - 收款码占位图（建议 600x600 px）

收款码正式使用时请上传到云存储，路径在 `paymentConfig` 集合中配置。
